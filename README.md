# Purice Mwero portfolio

Personal portfolio built with React, Vite, JavaScript and CSS.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## Contact form

The contact form uses FormSubmit to send messages to `puricekaka@gmail.com` and supports one optional image attachment (PNG, JPG or WebP, up to 10 MB). FormSubmit sends a one-time activation email to that inbox; confirm it before the form can deliver future messages.

Project content lives in `src/data.js`. The page is composed in `src/App.jsx` and styled in `src/App.css`.
